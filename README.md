# Module 5 – AI Resume Analyzer

## 📌 Project Overview

The AI Resume Analyzer is a Python-based mini project developed as part of Module 5 – AI Tools & Mini Project.

The project demonstrates how AI and Natural Language Processing concepts can be used to analyze resume content, identify technical skills, compare resumes with job descriptions, and provide improvement recommendations.

## 🎯 Objectives

- Understand how AI tools support coding and productivity.
- Analyze resume content using Python.
- Extract relevant technical skills.
- Compare resume content with job requirements.
- Identify matching and missing skills.
- Generate resume improvement suggestions.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Natural Language Processing concepts
- Google Colab
- AI Tools

## 🔍 Main Features

1. Resume text analysis
2. Technical skill extraction
3. Resume scoring
4. Job description matching
5. Matching skill identification
6. Missing skill identification
7. Resume improvement recommendations
